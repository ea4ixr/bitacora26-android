# Bitácora 26 móvil (Android)

Acompañante de [Bitácora 26](https://bitacora26.es) para PC: LOG de bolsillo.
La aplicación principal es la de PC; esta se adapta a ella (mismas reglas: hora en UTC, mayúsculas, operador en cada contacto).

- Apuntar contactos, ver el LOG, actividades y exportar ADI para importarlo en el PC.
- El APK lo fabrica GitHub Actions en cada cambio (pestaña Releases, versiones «movil-v…»).
